## 文件

- `index.html`：可直接双击运行的完整单文件网站，题目数据已内联。
- `questions.json`：完整题库、答案、译文、提示、推理与证据卡。
- `build.rb`：校验题库后重新注入 `index.html`。
- `data/ocr_lines.json`：95 张题图的 Vision OCR 坐标底稿。
- `REASONING_AUDIT.md`：95 题排除说明字段的逐题审计记录。
- `tools/rewrite_reasoning_v16.rb`：按本题真实选项、接续和易错点重建排除说明的确定性脚本。
- `tools/ocr_images.swift`：题图 OCR 工具。
- `tools/parse_problem6_ocr.rb`：题干、空格与选项拆分工具。
- `tools/pdf_pages_ocr.swift`：答案 PDF 页面识别工具。

## 更新题库

修改 `questions.json` 后运行：

```sh
ruby build.rb
```

构建脚本会检查：

- 题目 ID 唯一；
- 每题恰有四个选项；
- `solution` 是 1—4 的唯一排列；
- `starOptionId` 与 `starSlot` 一致；
- 完整句严格等于“固定前文＋正确选项原文＋固定后文”；
- 译文、推理和证据闪卡不为空。
