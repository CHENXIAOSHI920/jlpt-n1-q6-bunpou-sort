# JLPT N1 問題六 · 语法排序

版本：`v16.2`  
发布日期：2026-11-09

这是一个可直接部署到 GitHub Pages 的离线单文件学习工具。不需要后端、数据库、框架、外部字体或网络资源。

## 当前内容

- 正式版：95 道题，覆盖 19 个 N1 场次，范围为 2015.7—2026.7，每个场次第 36—40 题。
- 五个模块：排序、真题、证据、数学题、记录。
- 右侧索引分别记录排序、真题、数学题的当前状态和曾错历史。
- 95 道题的 `exactSentence → translation` 已完成逐题复核，`translationStatus` 全部为 `reviewed`。
- 90 道非 2026.7 题的循环式排除说明已按本题真实接续和反例重建。

## v16.2 重点

- 结果区★位置根据 `starSlot` 动态生成，21 道非第三空题不再误报“第三空位”。
- “最近一次结果”和“曾经答错”分开保存；重答正确不会删除曾错。
- 排序、真题、数学题的曾错状态分别保存，互不覆盖。
- 记录页显示当前正确率、当前待复习、曾错总数和分模块曾错来源。
- “重置全部记录”会清空三套当前状态与曾错历史。
- 旧版已知的当前错误会迁移到曾错历史；旧版已经丢失的历史不会被补造。
- 完整译文与 `evidence.meaning` 相同时只显示一次。
- 375px 记录页隐藏遮挡正文的悬浮索引按钮，并提供面板内索引入口。
- 真题模式离开当前题或刷新后会自动清空临时作答、反馈和查看答案状态；索引和曾错历史仍保留。
- 排序页可按“全部 / 排序错题 / 重点”筛选，并在当前筛选内连续上一题、下一题。
- 每题支持标记重点；标记持久保存，并在右侧索引显示金色★。
- 记录页提供“只刷排序错题”和“只刷重点”快捷入口。
- 数学题候选矩阵的★位置改为按当前题动态生成，`2025.12-36` 正确显示“★第2空”。

## JLPT 倒计时

倒计时使用以下日期表，并按 `Asia/Shanghai` 的自然日期计算：

```js
const JLPT_EXAM_SCHEDULE = [
  "2026-12-06",
  "2027-07-04",
  "2027-12-05"
];
```

考试当天显示 `0 / 今日 JLPT`；结束后自动切换下一场；日期表结束后显示 `-- / 待公布`，不会出现负数。
