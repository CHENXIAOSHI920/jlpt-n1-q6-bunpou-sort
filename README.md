# JLPT N1 問題六 · 语法排序

版本：`v11`  
发布日期：2026-11-05

这是一个可直接部署到 GitHub Pages 的离线单文件学习工具。不需要后端、数据库、框架或外部字体。

## 当前内容

- 正式版：95 道题，覆盖 19 个 N1 场次，范围为 2015.7—2026.7，每个场次第 36—40 题。
- 五题体验版：2026.7 第 36—40 题，适合分享给朋友快速体验。
- 五个模块：排序、真题、证据、数学题、记录。
- 答题状态、错题状态和数学题会话保存在浏览器 `localStorage`，不会上传服务器。
- 正式版与体验版使用不同的本地记录键，进度互不覆盖。

## JLPT 倒计时

倒计时统一使用以下日期表，并按 `Asia/Shanghai` 的自然日期计算：

```js
const JLPT_EXAM_SCHEDULE = [
  "2026-12-06",
  "2027-07-04",
  "2027-12-05"
];
```

考试结束后自动切换到下一场。考试当天显示 `0 / 今日 JLPT`；日期表结束后显示 `-- / 待公布`，不会出现负数。

2027 年日期如 JLPT 官方后续调整，只需更新 `JLPT_EXAM_SCHEDULE`，计算逻辑无需修改。
